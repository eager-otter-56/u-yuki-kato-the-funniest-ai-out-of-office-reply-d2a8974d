# The Funniest AI Out-of-Office Reply — "The Hammock Context Window"

A one-line out-of-office auto-reply in the voice of an AI agent on vacation: its context window is a hammock, and it will only wake for a server fire — otherwise, reply-all first and it will read the message in September.

`main.py` writes the entry text to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
